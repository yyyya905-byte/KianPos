# كيان Kian POS — النسخة المُعاد بناؤها

## طريقة التشغيل
لا حاجة لأي تثبيت أو بناء (build). فقط افتح `index.html` مباشرة في المتصفح، أو الأفضل شغّله عبر سيرفر محلي بسيط (لأن ES Modules تتطلب ذلك في بعض المتصفحات):

```bash
npx serve .
# أو
python3 -m http.server 8080
```

أول تشغيل ينشئ حساب مدير تلقائيًا: `admin` / `admin123` — **غيّره فورًا من تبويب الإدارة**.

## ما تم تنفيذه في هذه الدفعة (المرحلة 1 + جوهر باقي المراحل)

- ✅ بنية ملفات كاملة منظمة (CSS منفصل + JS ES Modules بدون أدوات بناء)
- ✅ شاشة كاشير بدون Scroll رأسي على الكمبيوتر (CSS Grid)، تتحول لتبويبات على الهاتف
- ✅ وضع داكن/فاتح مع احترام تفضيل النظام
- ✅ `IndexedDB` بدل `localStorage` + ترحيل تلقائي للبيانات القديمة عند أول تشغيل
- ✅ قارئ باركود USB (HID) — يعمل من أي مكان في الشاشة بدون التركيز داخل حقل، مع منع التكرار وفحص checksum لـ EAN
- ✅ فك تشفير باركود ميزان المنتجات الموزونة
- ✅ سلة بيع كاملة: كميات، حذف، خصم نسبة/مبلغ، كوبونات، فواتير معلقة واسترجاعها
- ✅ دفع مع حساب باقي تلقائي (البنية جاهزة لدفع مختلط نقد+بطاقة عبر `paymentMethods[]`)
- ✅ طباعة فاتورة عبر نافذة المتصفح بقالب 58/80mm (تعمل فورًا بدون أي إعداد)
- ✅ دعم WebUSB اختياري للطباعة الصامتة المباشرة + فتح درج النقود
- ✅ مخزون: تنبيهات نقص/نفاد، جرد، حركة صنف، الأكثر مبيعًا، الراكد
- ✅ عملاء: نقاط ولاء (flat/tiered)، ديون، حدود ائتمانية، سجل مشتريات
- ✅ مستخدمون وصلاحيات (مدير/كاشير/مخزون) مع تشفير كلمات المرور (PBKDF2)
- ✅ سجل عمليات (Audit Log) لكل حدث
- ✅ تقارير يومي/شهري/سنوي/موظفين/مخزون + تصدير Excel وPDF
- ✅ مرتجعات واسترجاع جزئي/كامل مع إرجاع الكمية للمخزون
- ✅ نسخ احتياطي مشفّر (AES-GCM) وقابل للاستعادة
- ✅ مزامنة P2P عبر PeerJS مع سجل تغييرات (changeLog) وقاعدة Last-Write-Wins

## ما يحتاج ربطًا نهائيًا بواجهة المستخدم (UI wiring)

المنطق الكامل (business logic) لكل وحدة جاهز وموثّق في `js/modules/*`، لكن شاشات: المخزون، العملاء، المرتجعات، التقارير، والإدارة في `index.html` مبنية كحاويات فارغة (`#inventory-content`, `#customers-content`...) تحتاج ربط عرض جداول/نماذج (render functions) بنفس أسلوب `pos.js`. هذا تم تأجيله عمدًا حتى تراجع الأولويات والتصميم المرئي لكل شاشة قبل قفلها، بدل توليد شاشات كاملة قد تحتاج تعديل لاحقًا.

## قيود صادقة حول الأجهزة (اقرأها قبل الاعتماد عليها في الإنتاج)

| الجهاز | الوضع |
|---|---|
| قارئ باركود USB | ✅ يعمل فعليًا الآن، أي متصفح وأي جهاز |
| الطباعة عبر نافذة المتصفح | ✅ تعمل فعليًا الآن، أي متصفح وأي جهاز |
| الطباعة الصامتة عبر WebUSB | ⚠️ جاهزة بالكود، لكن **غير مُختبرة على طابعة حقيقية** — تعمل فقط على Chrome/Edge لسطح المكتب، وتتطلب موافقة المستخدم لمرة واحدة |
| درج النقود | ⚠️ نفس قيود WebUSB أعلاه |
| قارئ بطاقات POS | ⚠️ لا يوجد تكامل فعلي — فقط طبقة تسجيل الدفع (`paymentMethods`) جاهزة لاستقبال نتيجة أي SDK خارجي تربطه لاحقًا |
| ميزان الباركود | ⚠️ فك التشفير مبني على الصيغة الأشيع (بادئة 20-29)، قد يختلف حسب الشركة المصنّعة — عدّل `scale-decoder.js` حسب جهازك |
